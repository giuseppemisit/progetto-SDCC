Caricamento massivo da file

Importa più documenti in un'unica operazione a partire da un file .csv o .json. Ogni riga valida genera un documento in archivio, completo di embedding semantico; le righe non valide vengono segnalate senza interrompere l'elaborazione delle altre.

Formato dei file accettati ed esempi
CampoObbligatorioNote
nomeSìMassimo 255 caratteri
descrizioneNoTesto libero
tipologiaNoMassimo 100 caratteri
data_documentoNoFormato ISO AAAA-MM-GG
ufficioNoMassimo 200 caratteri
firmatariNoTesto libero, più nomi separati da ;

  • Il CSV deve avere la riga di intestazione con i nomi dei campi; il separatore è la virgola e i valori che contengono virgole vanno racchiusi tra virgolette.
  • Il JSON deve contenere un array di oggetti, anche nel caso di un solo documento.
  • Entrambi i file devono essere codificati in UTF-8.
  • Le colonne o le chiavi non riconosciute vengono ignorate; i campi lasciati vuoti sono importati come valore assente.
